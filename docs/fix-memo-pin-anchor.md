# 붙임쪽지 압정 — 해상도가 달라도 같은 자리 (2026-08-05, 완료)

## 증상 (사용자 신고)

같은 페이지(`/improve`)를 창 크기가 다른 두 화면에서 열면 압정이 서로 다른 곳에 찍혔다.
좁은(확대된) 화면에서는 표의 체크박스 열 옆 — 요청 #39 "체크박스위치"가 가리키는 바로 그 지점 —
에 있던 압정이, 넓은 화면에서는 본문 왼쪽 **빈 여백**으로 밀려나 무엇을 가리키는지 알 수 없었다.

## 원인

좌표를 **레이어 폭의 %**로 저장했다(`memo.pos`). 그 레이어는 `left: 64px(레일) ~ right: 0`,
즉 **화면 전체**라서 창이 넓어지면 100%의 실제 폭도 같이 늘어난다.
반면 본문은 `PageContainer`가 **최대 1400 + 가운데 정렬**이라 넓어지지 않고 가운데로 모인다.

```
1366:  |rail|■■■■■■■■ 본문(1292) ■■■■■■■■|      x=6% → 본문 왼쪽에서 78px  (표 위)
1920:  |rail|   여백   | 본문(1400) |   여백   |   x=6% → 본문 왼쪽에서 -112px (여백)
```

같은 6%가 화면에 따라 표 안이 되기도 하고 여백이 되기도 한다 — "화면에 따라 다른 곳에 고정돼 보인다".

## 조치 — 기준을 화면에서 **본문 칸**으로, 단위를 %에서 **px**으로

사용자 선택(2026-08-05): *본문(표) 기준* — 해상도가 달라도 표의 같은 지점 옆에 남는 쪽.

1. **레이어 안에 본문 칸과 같은 상자를 겹쳤다.** 기존 fixed 레이어(레일 오른쪽~화면 끝) 안에
   `width:100% / max-width:1400 / mx:auto` 래퍼를 두고 `layerRef`를 그 래퍼에 건다.
   좌표의 (0,0)이 `PageContainer`의 좌상단과 같아진다. 끄는 범위도 본문 칸 안으로 제한된다.
2. **저장 단위를 px으로.** 표는 열 폭·행 높이가 고정이라 비율보다 px이 "그 지점 옆"을 지킨다.
   특히 세로 — 기존엔 화면 높이의 %라서 1080↔1440 모니터를 오가면 압정이 아래위로 밀렸다.
3. **저장 키를 `memo.pos` → `memo.pos2`로.** 기준이 달라 옛 값(%)을 그대로 읽으면 엉뚱한 자리가 된다.
   옛 좌표를 가진 쪽지는 기본 자리(메모 버튼 아래)로 한 번 돌아가고, 다시 옮기면 그 자리에 굳는다.
   (당시 쪽지 1건뿐이라 변환 코드를 두는 것보다 단순.)

`toPct`/`toPx` 변환 함수는 필요가 없어져 삭제. clamp·끌기·슬롯 배정은 모두 px 한 단위로 정리됐다.

## 검증 (dev 3600, 실측)

임시 상자에 실제와 같은 CSS를 넣어 본문 칸(`PageContainer`, computed `max-width:1400px`)과 비교:

| 창 폭 | 본문 칸 left~right | 쪽지 레이어 left~right | 일치 |
|---|---|---|---|
| 1366 | 64 ~ 1356 | 64 ~ 1356 | ✅ |
| 1920 | 287 ~ 1687 | 287 ~ 1687 | ✅ |

- 래퍼가 클릭을 막지 않는지: 래퍼의 computed `pointer-events`는 `none`(상속) — 빈 곳을 누르면
  아래 페이지 요소가 잡히고, 쪽지(`pointer-events:auto`) 위에서만 쪽지가 잡힌다. ✅
- 상단바 높이 55·레일 폭 64는 1366/1920에서 동일 → 세로 px 기준도 흔들리지 않는다. ✅
- `npm run type-check` 통과, 콘솔 에러 없음.

## 남은 것 / 참고

- **로그인 상태의 실제 쪽지 화면은 미검증** — 쪽지 레이어는 팀원 로그인에서만 뜨는데 dev 프리뷰에
  세션이 없다(비밀번호는 대신 입력하지 않는다). 배포 후 사용자가 압정을 한 번 옮겨 두고,
  다른 해상도에서 열어 같은 자리인지 확인하면 된다.
- 레이어 상단 기준 `TOPBAR_H = 53`인데 실제 상단바 높이는 55(2px 차이, 기존부터). 모든 화면에서
  같은 값이라 이번 증상과는 무관해 손대지 않았다.
- 본문 폭은 `layout.maxWidthWide`(1400) 고정으로 맞췄다. 상세(1200)·울트라(1680) 폭 페이지에서는
  본문 경계와 살짝 어긋나지만, 쪽지가 화면 밖으로 나가지는 않는다.
